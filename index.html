Architecture Details

ICD-10 Clinical Note Processing Pipeline

1. Extract Module: Reads unstructured clinical physician notes (`data/raw_notes.json`) using Pandas with validation.

2. Transform Module: Invokes `google-genai` SDK using `gemini-3.8-flash`. Applies Pydantic schema enforcing structured JSON attributes (`icd10_code`, `icd10_description`, `reasoning`).

3. Quota Engine: Includes precise 12-second request pacing and exponential backoff to fit within free-tier API quotas (5 RPM / 20 RPD).

4. Load Module: Persists records into DuckDB (`clinical_notes.duckdb`) columnar database with deduplication logic.

[data/raw_notes.json] ──> Extract (Pandas) ──> Transform (Gemini AI + Pydantic) ──> Load (DuckDB)
